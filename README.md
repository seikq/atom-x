# ATOM-X: Academia Atómica

Juego educativo sobre átomos, partículas e isótopos.

## Jugar online

1. Ve a **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **(root)**
4. Guarda y espera 1-2 minutos
5. Abre: **https://seikq.github.io/atom-x/**

## Jugar en el PC

Descarga `index.html` y ábrelo con doble clic en Chrome, Edge o Firefox.

No necesitas instalar nada ni volver a configurar el juego.
